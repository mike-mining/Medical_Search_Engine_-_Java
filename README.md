# Medical Search Engine - Java

This is elements of a University project that I completed when studying BSc Computer Science in 2012.

A Java search Engine that ranks medical documents against a user query using three Machine Learning algorithms.

| Algorithm | Role |
|---|---|
| **TF-IDF** | Converts documents and queries into weighted term vectors |
| **Cosine Similarity** | Measures angle-based similarity between vectors |
| **K-Means Clustering** | Group related documents to apply a relevance boost |
